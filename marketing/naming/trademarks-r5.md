# Name screen, round 5: twelve "light + days/evening" names

Screened 24 Oct 2026. This is not legal advice and not a clearance search.

## What was searched, and what could not be

- **US trademarks:** Trademarkia, each name as one joined word
  (`?q=brighterdays`) and as separate words (`?q=brighter%20days`), plus the
  singular/plural variant where it mattered (`brighter day`, `softer day`,
  `warmer day`, `golden evenings`, `bright evening`, `glow day`, `lantern day`).
  Records worth reporting were opened on their own pages.
- **Every one-word search returned 0 results** except `brighterdays` (one dead
  mark). As round 3 showed, the one-word search is not proof of absence, so the
  two-word search is the one relied on below. That search returns a ranked list
  and only its first page (10 results) is readable; an exact match ranks first
  wherever one exists (BRIGHTER DAYS, SUNSHINE DAYS, EVENING GLOW, GOLDEN
  EVENING, GENTLE LIGHT all did). For Brighter Days page 2 was also read.
- **Not reachable from this session:**
  - EUIPO TMview (`tmdn.org/tmview/api/search/results?...`): connection reset (ECONNRESET), as in every earlier round.
  - WIPO Global Brand Database (`branddb.wipo.int`): returns an ALTCHA proof-of-work verification page, no results.
  - **So EU, UK, WIPO/Madrid, Japan and China are NOT covered.** Run the
    shortlist through TMview, the WIPO Global Brand Database and J-PlatPat by
    hand before filing.
- **Apps, companies, books, songs, podcasts:** general web search, plus searches
  restricted to apps.apple.com and play.google.com. The search engine indexes
  the stores thinly, so "no app found" is weak evidence; search both stores
  directly before deciding.

Verdicts: **CLEAR** nothing relevant found / **CAUTION** something similar, a
crowded word, or an association worth weighing / **CONFLICT** the same or a
dominant name is registered or used in software, wellness or self-improvement.

### A mark that touches every "... Days" name

**DAYS**, MD Apps LTD (Macclesfield, GB), serial 90758581, reg. 6908753,
**live/registered** 2022, class 9: *downloadable mobile application software
... countdown timers and alarms that remind users of daily routines, events,
birthdays...* (https://www.trademarkia.com/days-90758581). It is a single,
common word and every candidate adds a distinctive adjective, so it is
unlikely to block any of them on its own, but it is a live class-9 app mark
on the shared word and an examiner may cite it.

  is the stock phrase for "after a hard time", which reads as depression or
  recovery rather than an everyday journal.

Similarity to BetterMe:

  B, the ending *-ter*, the comparative form and the self-improvement promise

  Days" are one sound apart, and **Better Days** is itself an existing
  mood-tracking and journaling app on Google Play
  (https://play.google.com/store/apps/details?id=com.somaedge.betterdays).
  Moving from "Better Me" to "Brighter Days" does not put clear distance
  between this app and BetterMe.

**Verdict: CONFLICT.** A pending class-9 BRIGHTER DAY app mark with a sun logo,
a live class-41 BRIGHTER DAYS LIFE COACHING mark, a same-category journal
called *Brighter*, search results owned by Ariana Grande, and the closest
echo of BetterMe in the list.

**Verdict: CAUTION.** No exact mark, but LANTERN is a crowded live word in
software classes 9/42 and in 41/44, an end-of-life app is called Lantern, and
