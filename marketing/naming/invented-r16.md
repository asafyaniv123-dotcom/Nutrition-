# Name screen, round 16: eight invented words

Screened 24 Oct 2026. This is not legal advice and not a clearance search.

Candidates: Hayomi, Hilumo, Hinalu, Luzemi, Akarila, Mingalu, Hoyalu, Nuanila.
They passed the store and domain screen in `round16a.log` / `round16b.log`: no
App Store hit, no Play hit, and `.app` unused. Store title in every case:
"<Name>: Daily Reflection". The brief: one invented word, like Duolingo,
blended from several languages, with the meaning a little hidden.

## What was searched, and what could not be

- **US trademarks:** a quoted Trademarkia search, `?q=%22<name>%22`, for each
  name and for spellings one letter off.
  - **Calibration:** the same quoted search returned real marks for the near
    spellings (HAYAMI, HILUMA, AKARINA, AKARIA, MINGALA, LUSEMI). So its zeros
    are real zeros for the exact spelling. Trademarkia's "may be available"
    banner is boilerplate and was ignored.
  - **Near spellings searched:** hayami, hayumi, hiyomi · hiluma, hilumi,
    helumo · hinala, hanalu · luzami, lusemi · akarina, akaria · mingala,
    mingalaba · hoyala, hoyolu · nuanilla, nuanela.
  - **Bare roots read for context:** `AKARI` (16 marks), `LUMO` (42) and
    `HOYA` (26).
- **Not reachable from this session:**
  - EUIPO TMview API (`tmdn.org/tmview/api/search/results?basicSearch=hilumo`):
    **connection reset**.
  - UK IPO (`trademarks.ipo.gov.uk/ipo-tmtext?wordSearchPhrase=hoyalu`):
    **HTTP 403**.
  - WIPO Global Brand Database (`branddb.wipo.int/en/similarname/results?...`):
    an ALTCHA bot check and an empty JS shell.
  - **So EU, UK, WIPO/Madrid, Japan (J-PlatPat), China (CNIPA) and Israel are
    NOT covered.** Run the finalist through TMview, the WIPO Global Brand
    Database and J-PlatPat by hand before filing.
- **Existing use:** a quoted web search for each name, plus follow-up searches
  on what came up. The search engine is US-only and indexes thinly. For every
  one of the eight names it returned only near spellings, with no page about
  the exact word. That is weak evidence of absence, not proof.
- **Domains:** `https://<name>.com` and `https://<name>.app` were fetched
  directly. Where a `.com` resolved, Verisign RDAP was read
  (`rdap.verisign.com/com/v1/domain/<name>.com`). YouTube was checked by
  fetching `https://www.youtube.com/@<name>` and reading the page title.
- **Pronunciation and meaning** come from knowledge of the languages, checked
  against the web where a claim was specific (Spanish *minga* against the RAE,
  Proton's *Lumo*, *HOYA*). Katakana, Hebrew, Arabic and Chinese spellings are
  suggestions. **A native speaker of each language should confirm them before a
  decision.**

Verdicts:
- **CLEAR:** nothing relevant found.
- **CAUTION:** a similar mark, an unhelpful reading, or a name already in use,
  explained in the section.
- **CONFLICT:** the identical mark is live, it sits in a class that matters
  (9/41/42/44/45), or it dominates the search results.

Sound rating: 1 (awkward) to 5 (rolls off the tongue). Stress is shown in capitals.

**Romance-language note that applies to four names.** Spanish, Portuguese,
French and Italian do not pronounce an initial H. So Hayomi, Hilumo, Hinalu and
Hoyalu are said *Ayomi*, *Ilumo*, *Inalu* and *Oyalu* in four of the eleven
languages. That is harmless, and in Hilumo's case it helps. But it means a
listener in those languages will not write the H.

**English note that applies to three names.** An ending of *-lu* is heard as
"loo", British slang for toilet. This affects Hinalu, Mingalu and Hoyalu. It is
faint, and the same is true of Waterloo and Honolulu, but it is there.

## 1. Hayomi: Hebrew *hayom* (today) + mi

**Trademarks: no exact mark found**

  https://www.trademarkia.com/search/trademarks?q=%22hayomi%22

  https://www.trademarkia.com/search/trademarks?q=%22hayami%22
- `"hayumi"` 0, `"hiyomi"` 0.
- Classes 9/41/42/44/45: nothing.

**Existing use**
- The web search found nothing for the exact spelling. All results were the
  Japanese surname/given name **Hayami** (速水 / 早見): Saori Hayami, Show Hayami,
  Yu Hayami. *Hayomi* itself is **not** an established Japanese given name, but
  it sits one vowel from a common one.
  https://nameplay.org/name/Hayami
- YouTube `@hayomi` belongs to a channel titled **"Hayomi 하요미"**, a Korean
  creator. Korean is not one of the eleven languages, but the handle is gone.
- No app called *HaYomi* was found. The neighbours are Jewish daily-study apps:
  *Siddur Hayom* and *HaLimud HaYomi*.
  https://apps.apple.com/app/id6762453303

**Sound and meaning**

| Language | Said | Written | Notes |
|---|---|---|---|
| Hebrew | ha-yo-MI | הַיּוֹמִי | **A real word: "the daily".** It is the word in *הדף היומי* (Daf Yomi, the daily Talmud page), so an Israeli hears a religious-study echo. Not hidden at all in Hebrew. |
| Arabic | ha-YOO-mi | هايومي | *يومي* (yawmī) means "daily / my day", and *ها* is "here, look". So it reads as roughly "here is my day". Positive, but should be confirmed by a native speaker. |
| English | hah-YOH-mee | | Clean, with no slang found. |
| German | ha-YO-mi | | Clean. |
| Spanish / Portuguese / Italian / French | a-YO-mi | | Silent H. No meaning found. |
| Japanese | ha-YO-mi | ハヨミ | *yomi* is 読み (reading), and also 黄泉 (Yomi, the land of the dead in myth). The reading sense comes first, so the echo is faint. |
| Chinese (Simp. / Trad.) | hā-yōu-mǐ | 哈优米 / 哈優米 | Neutral. 米 means rice. |

- **Spelled after one hearing?** Mostly yes. The likely errors are
  *Hayomee*, *Ayomi* (Romance languages) and *Hayami*.

**Sound rating: 5** (ha-YO-mi). Three open syllables in an alternating CV
rhythm, sayable in every one of the eleven languages. It is the most
Duolingo-shaped name in this round.

**Domains**
- `hayomi.com` redirects (HTTP 307) to **GoDaddy's for-sale page**
  (`forsale.godaddy.com/forsale/hayomi.com`). RDAP shows it was registered on
  2020-03-14 with Afternic nameservers, so it is **for sale**. The price page
  returned 403, so the price is unknown.
- `hayomi.app`: **no DNS**, unused.
- YouTube `@hayomi`: **taken** (a Korean creator).

**Verdict: CLEAR.** Nothing legal was found, and the `.com` can be bought. The
one real question is for the owner. In Hebrew this is not a hidden blend. It is
the ordinary word *the daily*, with a Daf Yomi echo. In Arabic it is half-hidden.
In the other nine languages it is fully hidden.
