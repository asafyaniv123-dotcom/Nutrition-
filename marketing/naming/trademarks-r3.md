# Name screen, round 3: ten plain phrases

Screened 24 Oct 2026. This is not legal advice and not a clearance search.

## What was searched, and what could not be

- **US trademarks:** Trademarkia. Each name was searched as one joined word
  (`https://www.trademarkia.com/search/trademarks?q=sunnyme`) and as separate words
  (`?q=sunny%20me`). Hits worth reporting were opened on their record pages.
- **Caveat on the one-word search, found in this round:** `?q=sunnyme` returned
  no SUNNY ME, yet `?q=sunny%20me` found a live, registered SUNNY ME. **So a
  zero from the one-word search does not prove there is no two-word mark.** For
  every name below, the two-word search was also run. That search returns a
  ranked list and only its first page (10 results) is readable, but an exact
  match ranked first wherever one existed (SUNNY ME, GOOD TODAY, EVENING LIGHT,
  DAYS LIKE THESE).
- **Not reachable from this session:**
  - EUIPO TMview (`tmdn.org/tmview/api/...`): connection reset (ECONNRESET), as in rounds 1 and 2.
  - WIPO Global Brand Database (`branddb.wipo.int`): returns a proof-of-work CAPTCHA page, no results.
  - trademarks.justia.com and uspto.report: HTTP 403 in round 1, not retried.
  - **So EU, UK, WIPO/Madrid, Japan and China are NOT covered.** Before filing,
    run the shortlist through TMview, the WIPO Global Brand Database and J-PlatPat by hand.
- **Apps, companies, books, songs, podcasts:** general web search. The search
  engine indexes the app stores thinly, so "no app found" is weak evidence.
  Search both stores directly before deciding.

Verdicts: **CLEAR** nothing relevant found / **CAUTION** something similar or
something that owns the search results, explained / **CONFLICT** the same or
dominant name is registered or used in software or wellness.

### On similarity to BetterMe, for all ten

BetterMe's mark is the shape *[adjective] + Me*. Three candidates carry "Me":
**Sunny Me** has exactly that shape (adjective + Me, two words, upbeat), so it
is the one most likely to be read as a sibling of BetterMe. **Me in Progress**
puts "Me" first but keeps the idea BetterMe sells (a self being improved).
**Me These Days** puts "Me" first and describes rather than improves; it is the
furthest of the three. The other seven share nothing with BetterMe.
