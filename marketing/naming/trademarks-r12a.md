# Name screen, round 12a: nine names on present, be you and light

Screened 24 Oct 2026. This is not legal advice and not a clearance search.

Candidates: Present Days, Fully Present, Truly Present, Stay Present, Just Be You,
Be Fully You, You These Days, Be True, Be Bright.
Store title in every case: "<Name>: Daily Reflection".

## What was searched, and what could not be

- **US trademarks:** Trademarkia. Each name was searched as a **quoted phrase**
  (`?q=%22fully%20present%22`) and as **one joined word** (`?q=fullypresent`).
  The quoted search is working: it returned the single live FULLY PRESENT filing,
  9 JUST BE YOU records, 11 BE TRUE, 7 BE BRIGHT and 5 BE PRESENT, so a zero
  from it is a real signal for the US register.
  Reference searches were also run on `"be present"`, `bepresent` and `presently`.
- **Not reachable from this session:**
  - EUIPO TMview (`tmview.tmdn.org/tmview/api/...`): DNS failure (ENOTFOUND);
    the `tmdn.org/tmview/#/...` page returns an empty JavaScript shell.
  - EUIPO eSearch (`euipo.europa.eu/eSearch`): connection reset (ECONNRESET).
  - WIPO Global Brand Database (`branddb.wipo.int`): ALTCHA bot-check page, no results.
  - **So EU, UK, WIPO/Madrid, Japan and China are NOT covered.** Run the shortlist
    through TMview, the WIPO Global Brand Database and J-PlatPat by hand before filing.
- **Apps, companies, books, songs, podcasts:** general web search, plus searches
  restricted to apps.apple.com and play.google.com. The search engine indexes the
  stores thinly, so "no app found" is weak evidence.

Verdicts: **CLEAR** nothing relevant found / **CAUTION** something similar, or
something that owns the search results, explained / **CONFLICT** the same or
dominant name is registered or used in software or wellness.

## 1. Present Days

**Trademarks:** `"present days"` 0 results; `presentdays` 0 results.
https://www.trademarkia.com/search/trademarks?q=%22present%20days%22 ,
https://www.trademarkia.com/search/trademarks?q=presentdays

**Products:** nothing found under the exact name: no app, book, podcast, album or
newsletter. Search results are owned by journaling generally (Day One, The Daybook,
Daycast). Nearest name: *Present Joys*, a newsletter by Present Studio
(https://presentstudio.substack.com).

**Closeness to BePresent / Presently:** shares only the common word "present";
different structure (adjective + noun, not "Be" + present). Lower than the other
three "Present" names.

**Meaning:** "present day" means *nowadays*, so "Present Days" can read as "these
times / the modern era". "Present" also means a gift, so "present days" can read
as gift-giving occasions in English. Neither is negative. No similarity to BetterMe.

**Verdict: CLEAR** (with the general note that "present" is a crowded store word).
