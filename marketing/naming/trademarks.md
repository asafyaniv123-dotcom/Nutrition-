# Name screen: trademarks, existing uses, meanings

First screen, 24 Oct 2026. Not legal advice, and not a clearance search.

## What was searched, and what could not be

- **US trademarks:** Trademarkia (`https://www.trademarkia.com/search/trademarks?q=<name>`).
  Every name was searched as one word; risky ones were also searched as two words
  or as the nearest real variant. Trademarkia results shown are US (USPTO) records.
- **Not reachable from this session:** trademarks.justia.com and uspto.report
  (HTTP 403), the USPTO search API (call blocked), EUIPO TMview (connection reset).
  WIPO Global Brand Database and UK IPO are JavaScript search forms and were
  not queried. **So EU, UK, WIPO/Madrid, Japan and China are NOT covered here.**
  Before filing, run each shortlisted name through TMview, WIPO Global Brand
  Database and J-PlatPat by hand.
- **Companies/apps:** general web search, plus `site:apps.apple.com` and
  `site:play.google.com` searches. The web search engine indexes app stores
  thinly, so "no app found" is weak evidence. Search both stores directly.

Verdicts: **CLEAR** nothing found / **CAUTION** something similar, explained /
**CONFLICT** same name in software or wellness.

## Daysake

Trademarks: **nothing** for "daysake"
(https://www.trademarkia.com/search/trademarks?q=daysake).

Companies/apps: none found. Results were only about sake (World Sake Day,
WESAKE, sake apps).
Meaning: built from "for the day's sake". **In Japanese, *sake* (酒) means
alcohol / rice wine**, and English speakers know the word that way too. Read
by a Japanese or food-minded reader it can parse as "day + sake", i.e. day
drinking. That matters for an app that logs food.

**Verdict: CLEAR** on trademarks and companies. Note the sake reading before
choosing it.
